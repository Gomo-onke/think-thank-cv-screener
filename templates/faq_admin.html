Use this chatbot on your website and on WhatsApp

All channels answer from the questions below, so you only edit them in one place. Full steps: infobip/SETUP.md.

1. Your website

Paste this line just before </body> on any page. A chat button appears bottom-right.

<script src="{{ base }}/static/embed.js" async></script>

2. WhatsApp (through Infobip)

Infobip forwards each incoming WhatsApp message to this address (replace YOUR_SECRET with INFOBIP_WEBHOOK_SECRET):

{{ base }}/webhooks/infobip/whatsapp?secret=YOUR_SECRET
